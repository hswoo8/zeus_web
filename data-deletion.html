데이터 삭제 요청

앱: 미니제우스(MiniZeus) · 최종 수정일: 2026년 8월 17일

삭제 요청 방법

  1. 미니제우스 앱의 프로필 화면에서 게스트 ID를 눌러 전체 ID를 복사합니다.
  2. 아래 이메일로 제목에 “미니제우스 데이터 삭제 요청”을 적고, 본문에 전체 게스트 ID를 포함하여 보냅니다.
  3. 요청 확인 및 삭제 처리에는 최대 30일이 걸릴 수 있습니다.
이메일로 삭제 요청

문의 이메일: bakingstudio.beta@gmail.com

삭제되는 데이터

  • 게스트 ID와 해당 ID에 연결된 닉네임
  • 멀티플레이 경기 기록과 MMR·랭킹 기록
  • 게스트 ID와 연결된 문의 티켓 및 사용자가 선택하여 입력한 회신 이메일
  • 그 밖에 개발자 서버에서 해당 게스트 ID로 식별할 수 있는 데이터

보관될 수 있는 데이터와 기간

  • 개인과 다시 연결할 수 없는 집계 통계는 서비스 분석을 위해 계속 보관될 수 있습니다.
  • Google Analytics의 앱 인스턴스 기반 사용자·이벤트 데이터는 게스트 ID와 연결되지 않으며 속성 설정에 따라 최대 14개월 보관될 수 있습니다. 표준 집계 보고서는 이 보관 설정의 영향을 받지 않을 수 있습니다.
  • Firebase Crashlytics의 충돌·ANR 데이터와 관련 설치 식별자는 90일 동안 보관된 후 삭제 절차가 시작됩니다.
  • 일반적인 문의 티켓은 접수·답변·분쟁 대응을 위해 최대 180일 보관되지만, 삭제 요청에서 식별된 티켓은 요청 처리 범위에 포함됩니다.

기기에 저장된 데이터

앱을 삭제하거나 Android 설정에서 미니제우스의 앱 데이터를 삭제하면 기기에 저장된 게스트 ID, 게임 설정 및 로컬 진행 정보가 삭제됩니다. 기기 데이터 삭제만으로 서버 데이터 삭제 요청이 접수되지는 않으므로, 서버 데이터도 삭제하려면 위 절차를 이용하세요.

문의

앱 또는 개발자의 데이터 처리에 관한 자세한 내용은 미니제우스 개인정보처리방침을 확인하세요.

Data Deletion Request

App: MiniZeus · Last updated: August 17, 2026

How to request deletion

  1. In the MiniZeus profile screen, tap the guest ID to copy the full ID.
  2. Email us with the subject “MiniZeus Data Deletion Request” and include the full guest ID in the message.
  3. Verification and deletion may take up to 30 days.
Request deletion by email

Contact: bakingstudio.beta@gmail.com

Data that will be deleted

  • The guest ID and nickname linked to it.
  • Multiplayer match history, MMR, and ranking records.
  • Support tickets linked to the guest ID and an optional reply email supplied by the user.
  • Other data on the developer server that can be identified by that guest ID.

Data that may be retained

  • Aggregated statistics that can no longer be linked back to an individual may be retained for service analytics.
  • Google Analytics app-instance user-level and event-level data is not linked to the guest ID and may be retained for up to 14 months, depending on the property setting. Standard aggregated reports may not be affected by this retention setting.
  • Firebase Crashlytics crash and ANR data and associated installation identifiers are retained for 90 days before removal begins.
  • Ordinary support tickets may be retained for up to 180 days for acknowledgement, response, and dispute handling. Tickets identified in a deletion request are included in the request scope.

Data stored on the device

Uninstalling MiniZeus or clearing its Android app data removes the guest ID, game settings, and local progress stored on that device. This does not submit a server-data deletion request, so use the process above if you also want server data deleted.
